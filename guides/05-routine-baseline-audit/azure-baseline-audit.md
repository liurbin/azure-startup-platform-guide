# 例行基线审计

[英文版](azure-baseline-audit.en.md)

把下面的指令交给你的智能体，按约定周期检查安全、费用、错误与警告。实际审计需要相应的数据读取能力；本页不提供数据连接、定时器或自动执行工具。

审计关注范围不等于本库知识正文的覆盖范围；涉及网络、主机或备份等领域时，按所用服务的适用官方要求判断，不在本页展开配置实施，也不据此宣称完成全部安全控制或合规认证。

## 可复制的审计指令

```markdown
# Azure例行基线审计

按约定周期，对指定的Azure Global环境进行只读审计。结合实际可读取的信息，关注以下三项。

## 1. 安全
参照所用服务适用的官方安全基线，核对版本与适用范围，关注：
- 身份与权限、网络与数据保护。
- 日志审计，以及适用的主机与备份安全。
- 人工智能服务的访问控制与数据保护。

指出重要安全缺口，以及相较上次新增或恶化的风险。

## 2. 费用
关注：
- 支出趋势、异常增长和无法解释的持续费用。
- 预算、抵扣额度余额及到期情况。
- 按当前趋势，需要提前关注的支出风险。

说明主要变化来自哪里，哪些需要确认或采取行动。

## 3. 错误与警告
关注：
- 平台及人工智能服务的重要告警和重复错误。
- 配额、限流和服务健康问题。
- 需要行动的平台通知，以及仍未解决的重要事项。

区分实际业务影响与一般提示，避免逐条堆砌告警。

## 输出要求
- 先给简短结论，再按影响排列重要发现。
- 每项说明：发现了什么、影响什么、建议优先做什么，并附证据来源和观察时间。
- 有上次记录时比较变化；缺少数据或无法验证时明确说明，不当作审计通过。

## 边界
只检查并提出建议，不自动修改环境、权限或进行购买。
不展开企业级资产治理、研发运维流程、应用代码、人工智能应用设计或具体配置实施。
```
